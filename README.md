# Jader Nunes

Personal site for Jader Nunes, an engineering manager. These pages carry the same writing as [jadernunes.com](https://jadernunes.com): home, journey, work history, tech stack, iOS libraries, iOS projects, and contact.

The pages are hand-written HTML, CSS, and JavaScript. Photographs and company logos are files in this repository.

## Run it locally

From this folder:

```bash
python3 -m http.server 8080
```

Open [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

## Published copy

GitHub Pages serves this repository at <https://jadernunes.github.io/my-website/>.

The contact page lists an email address, a phone number, LinkedIn, GitHub, and a Calendly link. The message fields open the visitor’s email app. This site has no server and does not store form submissions.
